# 1. 店铺模块API

**API URL**

post {HTTP(S)地址}/api/{version}/shop

## 1.1. 店铺列表查询接口

### 1.1.1. SERVICE_TYPE

QUERY_SHOP_LIST

### 1.1.2. 请求参数

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| page | Y | Number | 1 | 页码，默认1 |
| pageSize | Y | Number | 50 | 每页条数.不超过200条; 默认100 |
| platform | N | String | EBAY,AMAZON,ALIEXPRESS | [平台](../commons/enums.html#店铺平台) |
| status | N | String | LOCK,UNLOCK | [启停状态](../commons/enums.html#店铺状态) |
| siteCode | N | String | US,CA | [店铺关联的站点国家](../commons/enums.html#国家列表) |
| name | N | String | Lazada1号店 | 店铺名称 |
| authExpiredStatus | N | String | NORMAL | 店铺授权状态： NORMAL、NO_AUTH、EXPIRED |
| createTimeFrom | N | String | 2025-04-15 | 店铺创建起始时间 |
| createTimeTo | N | String | 2025-04-15 | 店铺创建结束时间 |

### 1.1.3. 返回参数

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| errorCode | Y | String | “DATA_INPUT_ERROR” | [错误码](../commons/enums.html#错误码) |
| errorMsg | Y | String | “输入参数不对” | 业务错误信息 |
| state | Y | String | success | [请求结果](../commons/enums.html#State) |
| total | Y | Number | 100 | 总条数 |
| result | Y | List<Shop> |  | 店铺信息,详情查看下表 |

#### Shop(店铺)

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| name | Y | String | “Lazada1号店” | 店铺名称，最大50字符 |
| platform | Y | String | “EBAY,AMAZON,ALIEXPRESS” | [平台枚举，最大20字符](../commons/enums.html#店铺平台) |
| status | Y | String | LOCK,UNLOCK | [店铺启停状态](../commons/enums.html#店铺状态) |
| siteCode | N | String | US,CA | [店铺对应国家站点](../commons/enums.html#国家列表) |
| authExpiredStatus | Y | String | NO_AUTH,NORMAL,EXPIRED | 授权状态 |
| shopId | Y | Long | 11111 | 店铺id |
| onlineShopId | N | String | 100010 | 线上店铺id |
| shopGroupVOList | N | List<ShopGroup> |  | 店铺对应店铺组信息 |
| createTime | Y | Long | 1744686179000 |

#### ShopGroup

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| id | Y | Long | 1 | 店铺组id |
| shopGroupName | Y | String | 店铺组名称 | 店铺组名称 |

**请求示例:**

```
curl --location --request POST 'https://gerp-test1.800best.com/api/v1/shop' \
--form 'appId="TEST"' \
--form 'serviceType="QUERY_SHOP_LIST"' \
--form 'bizParam="{\"page\":1,\"pageSize\":3}"' \
--form 'timestamp="1756865700001"' \
--form 'sign="6a7a3ee175d0cfab63198c5e49bddc60"'
```
