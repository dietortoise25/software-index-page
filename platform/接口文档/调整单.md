# 1. 调整单模块API

**API URL**

post {HTTP(S)地址}/api/{version}/adjustment

## 1.1. 调整单查询接口

### 1.1.1. SERVICE_TYPE

QUERY_ADJUSTMENT_LIST

### 1.1.2. 请求参数

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| warehouseName | N | String | 马来仓库 | 仓库名称 |
| source | Y | String | *AUTO* | [调整单类型，见枚举](../commons/enums.html#调整单类型) |
| autoSource | N | String | *EXTERNAL_ADJUST* | Source=auto时，必传字段，子分类，见枚举   [调整单子类型](../commons/enums.html#调整单子类型) |
| createTimeFrom | N | String | 2022-09-05 | 创建时间起始 |
| createTimeTo | N | String | 2022-09-05 | 创建时间结束 |
| updateTimeFrom | N | String | 2022-09-05 | 更新时间起始 |
| updateTimeTo | N | String | 2022-09-05 | 更新时间结束 |
| number | N | String | 2011asd | 调整单号 |
| skuKeyWord | N | String | 2011asd | 多字段检索，商品编码，商品名称 |
| page | Y | Number | 1 | 页码，默认1 |
| pageSize | Y | Number | 100 | 每页条数.不超过200条; 默认100 |

### 1.1.3. 返回参数

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| errorCode | Y | String | “DATA_INPUT_ERROR” | [错误码](../commons/errors.html#错误码) |
| errorMsg | Y | String | “输入参数不对” | 业务错误信息 |
| state | Y | String | success | [请求结果](../commons/enums.html#State) |
| total | Y | Number | 100 | 总条数 |
| result | Y | List<Adjustment> |  | 详见 Adjustment |

Adjustment (调整单)

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| adjustmentNumber | Y | String | A20220905 | 调整单号 |
| source | Y | String | *AUTO* | [调整单类型，见枚举](../commons/enums.html#调整单类型) |
| autoSource | N | String | *EXTERNAL_ADJUST* | Source=auto时，必传字段，子分类，见枚举  [调整单子类型](../commons/enums.html#调整单子类型) |
| warehouseName | Y | String | 马来仓库 | 调整仓库名称 |
| remark | N | String | Quick | 备注 |
| createTime | Y | String | 2022-09-05 15:27:18 | 创建时间 |
| adjustmentSkuVOList | Y | List<AdjustmentSku> |  | 调整单商品 |

AdjustmentSku(调整单商品)

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| sku | Y | String | S90 | 商品sku |
| title | Y | String | 商品标题 | 商品标题 |
| color | N | String | 颜色 | 规格-颜色 |
| itemPackage | N | String | 包装 | 规格-包装 |
| size | N | String | 尺寸 | 规格-尺寸 |
| storageLocationCode | N | String | SYS LOC | 库位 |
| availableQuantity | Y | Long | 100 | 可用库存 |
| allocatedQuantity | Y | Long | 100 | 占用库存 |
| totalQuantity | Y | Long | 100 | 总库存 |
| totalAfter | Y | Long | 100 | 调整后总库存 |
| difference | Y | Long | 100 | 调整差额 |
| availableAfter | Y | Long | 100 | 调整后可用库存 |

## 1.2. 调整单创建接口

### 1.2.1. SERVICE_TYPE

CREATE_ADJUSTMENT_ORDER

### 1.2.2. 请求参数

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| warehouseName | Y | String | 马来仓库 | 仓库名称 |
| externalNumber | N | String | C20220905 | 外部单号 |
| remark | N | String | Quick | 备注 |
| adjustmentType | N | String | AVL_FINAL | [调整类型](../commons/enums.html#调整单调整类型枚举)，默认为可用总量调整 |
| adjustSkuList | Y | List< adjustSku> |  | 见adjustSku |

adjustSku (调整单商品)

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| sku | Y | String | S90 | 商品编码 |
| title | N | String | 无刷吸尘器 | 商品名称 |
| storageLocationCode | N | String | SYS LOC | 库位编码。良品库位传 SYS LOC，不良品库位传 Unavailable LOC，支持客户通过自定义库位编号进行调整。 |
| adjustmentQtyStr | Y | Long | 100 | 调整数量，支持正负数，正数表示调增，负数表示调减。 |

### 1.2.3. 返回参数

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| errorCode | Y | String | “DATA_INPUT_ERROR” | [错误码](../commons/errors.html#错误码) |
| errorMsg | Y | String | “输入参数不对” | 业务错误信息 |
| state | Y | String | success | [请求结果](../commons/enums.html#State) |
