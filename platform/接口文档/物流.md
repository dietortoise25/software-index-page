# 1. 物流模块API

## 1.1. 头程查询接口

post {HTTP(S)地址}/api/{version}/firstLeg

### 1.1.1. SERVICE_TYPE

QUERY_FIRST_LEG_ORDER_LIST

### 1.1.2. 请求参数

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| firstLegNumber | N | String | T987654321 | 头程单号，最大50个字符 |
| status | N | String | NEW | 参见[头程状态](commons/enums.md#头程状态) |
| updateTimeFrom | N | String | 2021-08-01 | 更新时间（范围开始） |

| result | Y | List |  | 详见FirstLegOrder |

### 1.6.2. 请求参数

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| firstLegNumber | N | String | T2602051845355 | erp头程单号，最大50个字符 |
| customNumber | N | String | TP202602050012 | 参考号，最大50个字符 |
| delFlag | N | Boolean | true | 默认true，头程单撤回到新建状态并删除；false，头程单撤回到新建状态但不删除。如果已是新建状态则不撤回。 |

`头程单号和参考号至少填写一个`

| errorMsg | Y | String | “输入参数不对” | 业务错误信息 |
| state | Y | String | success | [请求结果](../commons/enums.html#State) |
| bizContent | Y | String | json | 详见PageData |

**请求示例:**

