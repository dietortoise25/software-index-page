# 1. 报表模块API

**API URL**

post {HTTP(S)地址}/api/{version}/report

## 1.1. shopee交易明细查询接口

### 1.1.1. SERVICE_TYPE

QUERY_SHOPEE_TRANSACTION_DETAIL_LIST

### 1.1.2. 请求参数

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| shopIdList | N | List | [1001] | 店铺id列表，不超过100个与 shopNameList 二选一必填，若两者都提供，则以本参数为准 |

| adjustmentLevel | N | String | ORDER | 调整维度，当type=2时必须，ORDER(订单) 或 SHOP(店铺) |
| payoutTimeFrom | N | Date | 2022-09-05 | 回款时间起始 |
| payoutTimeTo | N | Date | 2022-09-05 | 回款时间结束 |
| updateTimeFrom | N | Date | 2022-09-05 00:00:00 | 更新时间起始 |
| updateTimeTo | N | Date | 2022-09-05 10:00:00 | 更新时间结束 |
| onlineOrderId | N | String | 2011asd | 平台线上单号 |
| onlineOrderIdList | N | List | ["2011asd"] | 平台线上单号列表 |
| page | Y | Integer | 1 | 页码，默认1 |
| pageSize | Y | Integer | 100 | 每页条数，不超过200条，默认100条 |

| 参数 | 是否必须 | 类型 | 示例 | 备注 |
