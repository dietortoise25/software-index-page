# 1. 千易OpenApi

本文档分三部分：

- 系统开放接口，主要给想对接千易的三方ERP系统使用
- 自营仓对接规范
- 物流对接规范

地址：

| 环境 | 地址 |
| --- | --- |
| 国内生产环境 | www.qianyierp.com |
| 海外生产环境 | asia.qianyierp.com |
| 测试环境 | gerp-test1.800best.com |

文中的{version}字段，没有特别描述都是v1。

所有和推送相关的接口，格式统一返回form-data，例如PUSH_SALES_ORDER_SHIPPING_INFO、PUSH_TRACKING_PACKAGE、PUSH_RETURN_ORDER_INFO、PUSH_ASN_ORDER等
如果想要json格式，请联系千易开白名单
