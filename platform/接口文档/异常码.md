# 1. 错误码

| 错误码 | 备注 |
| --- | --- |
| SYSTEM_ERROR | 系统异常,请联系官方对接人员 |
| SIGNATURE_ERROR | 签名异常 |
| APP_NOT_EXIST | appId不存在 |
| SERVICE_TYPE_NOT_EXIST | 接口不存在 |
| APP_ID_CANNOT_BE_BLANK | appId不能为空 |
| SIGNATURE_CANNOT_BE_BLANK | 签名不能为空 |
| SERVICE_TYPE_CANNOT_BE_BLANK | 请求接口不能为空 |
| TIMESTAMP_CANNOT_BE_BLANK | 时间戳不能为空 |
| SERVICE_TYPE_NOT_ALLOW | 接口未授权或不存在 |
