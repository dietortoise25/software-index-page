这张图本质上不是“内容图”，而是一个：

> Hero Section 的「氛围型视觉锚点（Visual Anchor）」

它的作用是：

- 给用户第一眼建立“AI / 数字化 / 未来生产力”的认知
- 平衡左侧大量文字
- 提供页面层次感与呼吸感
- 提升品牌感，而不是解释业务

所以前端不要把它当普通 `<img>` 去塞。

---

# 给前端的明确交付说明

## 一、用途定位

位置：

- About 页 Hero Section
- 第一屏右侧视觉区域

作用：

- 视觉氛围图
- 品牌情绪图
- 科技感补强

不是：

- Banner
- 插画正文
- 卡片内容

---

# 二、推荐布局（非常重要）

## 正确布局

```txt
------------------------------------------------
|                                              |
|   左侧文案              右侧视觉元素          |
|                                              |
|   标题                  [ AI 场景图 ]         |
|   描述                                         |
|                                              |
------------------------------------------------
```

图应该：

- 偏右
- 偏下
- 不居中
- 不抢标题

因为标题才是信息核心。

---

# 三、CSS 使用规范

## 推荐方式

不要：

```html
<img />
```

而是：

```css
position: absolute;
right: -80px;
top: 50%;
transform: translateY(-50%);
opacity: 0.9;
pointer-events: none;
user-select: none;
```

原因：

- 它是“背景型前景元素”
- 不参与文档流
- 不影响响应式排版

---

# 四、尺寸建议

## Desktop

```css
width: 680px;
max-width: 48vw;
```

不要超过：

- 页面宽度的 50%

否则会压标题。

---

## 超宽屏（2K / 4K）

建议：

```css
scale: 1.1;
opacity: 0.85;
```

让画面有空间感。

---

## Mobile

移动端不要完整显示。

建议：

### 方案A（推荐）

直接隐藏：

```css
display: none;
```

因为移动端文字优先。

---

### 方案B（高级方案）

只保留局部 glow：

```css
mask-image: linear-gradient(...);
```

保留一点蓝色氛围即可。

---

# 五、一定要加的视觉效果

## 1. 外发光（核心）

否则图会“死”。

```css
filter: drop-shadow(0 0 40px rgba(0, 255, 220, 0.18));
```

---

## 2. 与背景融合

页面背景是深蓝。

所以图片边缘必须淡出：

```css
mask-image: radial-gradient(circle, #fff 55%, transparent 100%);
```

否则会像贴纸。

---

## 3. 微漂浮动画（高级感来源）

```css
@keyframes float {
  0% {
    transform: translateY(0px);
  }
  50% {
    transform: translateY(-8px);
  }
  100% {
    transform: translateY(0px);
  }
}
```

持续时间：

```css
animation: float 6s ease-in-out infinite;
```

非常关键。

没有动画会像 PPT。

---

# 六、不要做的事（重点）

## 不要：

### ❌ 加边框

### ❌ 加卡片背景

### ❌ box-shadow 黑影

### ❌ 居中摆放

### ❌ 放在文字上面

### ❌ 做成轮播图

### ❌ 加 hover 放大

这是品牌视觉元素，不是商品图。

# 九、设计理念（给前端理解）

这张图不是“人在操作AI”。

真正表达的是：

> “个体能力被数字系统放大”

所以：

- 人物很小
- 数据面板很大
- 发光来自系统
- 人被包围在能力场中

这叫：

```txt
Individual Leverage Visualization
（个体杠杆化视觉）
```

它本质是在视觉上支撑：

> “重新定义一个人的生产力”

这个标题。
