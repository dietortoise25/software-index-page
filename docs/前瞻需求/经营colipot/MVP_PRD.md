# AI 经营 Copilot MVP - PRD（Product Requirement Document）

## 一、产品背景

传统 BI 系统存在几个长期问题：

- Dashboard 使用率低
- 数据分析高度依赖人工
- 业务方需要频繁提需求
- 数分团队长期被动响应
- 经营信息流转效率低

企业真正缺少的并不是数据本身。

而是：

# “持续经营认知”

即：

- 更快发现问题
- 更快理解问题
- 更低成本形成经营协作

因此，本产品不再以 Dashboard 为中心。

而是：

# 构建一个 AI 驱动的经营 Copilot（经营副驾驶）

---

# 二、产品定位

## 产品名称（暂定）

AI Business Copilot

---

## 产品定位

一个：

# 「事件驱动 + AI解释 + 协作增强」

的经营辅助系统。

---

## 不做什么

MVP 阶段：

不做：

- 全自动经营决策
- AI 自动执行高风险操作
- 复杂 BI 平台
- 大型数据中台
- 多租户复杂权限体系

---

## 核心目标

帮助业务团队：

- 自动发现异常
- 自动生成经营解释
- 自动形成协作上下文

---

# 三、目标用户

## 核心用户

### 1. 电商运营经理

需要：

- 快速发现异常
- 快速定位原因
- 快速形成行动

---

### 2. 广告投放负责人

需要：

- 高频监控 ROI
- 快速发现广告异常
- 理解流量变化

---

### 3. 中小团队老板

需要：

- 快速了解经营状态
- 降低管理信息成本

---

## 非目标用户（当前阶段）

- 专业数据分析师
- 大型企业 BI 团队
- 复杂财务分析场景

---

# 四、核心产品理念

传统 BI：


经营 Copilot：

```text id="gf19m0"

```

# 五、MVP 核心功能

---

# 功能 1：经营事件流（核心）

## 描述

系统自动生成经营事件。

例如：

```text id="6yyxvz"
[异常]
TikTok 美国 ROI 下降 18%

主要原因：
- CPM上涨
- CTR下降

建议关注：
广告素材疲劳
```

---

## 目标

替代：

- 手工日报
- 人工截图
- 手工同步

---

## MVP 支持事件

| 类型     | 示例       |
| -------- | ---------- |
| ROI异常  | ROI下降    |
| 销量异常 | GMV波动    |
| 库存异常 | SKU缺货    |
| 广告异常 | CPM暴涨    |
| 利润异常 | 毛利率下降 |

---

# 功能 2：AI 自动经营日报

## 描述

每天自动生成：

- GMV
- ROI
- Top SKU
- 核心异常

并自动推送飞书。

---

## 示例

```text id="v96hyf"
今日经营摘要：

GMV +12%
利润 -5%

主要原因：
冷冻虾采购成本上涨。
```

---

# 功能 3：AI 异常解释

## 描述

系统自动分析：

```text id="7t3yrn"
为什么指标变化？
```

并生成：

- 可能原因
- 相关上下文
- 历史趋势

---

## 示例

输入：

```text id="ev7n1e"
ROI下降18%
```

输出：

```text id="1g2ib0"
可能原因：

- CPM上涨
- CTR下降
- Landing Page加载变慢
```

---

# 功能 4：ChatBI（核心）

## 描述

用户通过自然语言提问。

---

## 示例

```text id="o7ajm0"
为什么今天销量下降？
```

```text id="r6v97x"
最近利润变化趋势？
```

```text id="z3sd5q"
哪个SKU贡献最高利润？
```

---

## MVP 范围

仅支持：

- 单轮问答
- 基础经营指标
- 简单趋势分析

---

# 功能 5：飞书 Push

## 描述

系统自动：

- 推送日报
- 推送异常
- 推送 AI 分析

---

## Push 原则

只 Push：

- 高价值异常
- 关键经营变化

避免：

- 高频骚扰
- 通知疲劳

---
