# 一、页面定位

这是个人网站中的一个路由页面。

不是：

- 独立官网
- 在线简历
- 传统作品集
- SaaS Landing Page

页面本质：

> 一个“认知型个人品牌页面”。

核心目标：

不是介绍“我会什么”。

而是：

## 展示我是如何形成现在这套思考方式与工作方式的。
