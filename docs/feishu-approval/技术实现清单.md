# 负责人变动审批 — 技术实现清单

> 三方审批模式 · API 管理审批定义和实例 · webhook 回调更新数据库

## 数据库改动

### 1. operators 表加飞书 ID

```sql
ALTER TABLE internal.operators ADD COLUMN feishu_open_id VARCHAR(100);
```

用于 server 创建审批实例时指定审批人。

### 2. shop_operators 表加时间线和主负责人

```sql
ALTER TABLE internal.shop_operators ADD COLUMN is_primary BOOLEAN DEFAULT false;
ALTER TABLE internal.shop_operators ADD COLUMN effective_from DATE;
ALTER TABLE internal.shop_operators ADD COLUMN effective_to DATE;
```

### 3. 变动记录表（只增不删不改）

```sql
CREATE TABLE internal.shop_operator_changes (
  id BIGSERIAL PRIMARY KEY,
  shop_id BIGINT NOT NULL,
  operator_id BIGINT NOT NULL,
  change_type VARCHAR(20) NOT NULL,
  effective_from DATE NOT NULL,
  effective_to DATE,
  reason TEXT NOT NULL,
  submitted_by VARCHAR(100),
  status VARCHAR(20) DEFAULT 'pending',
  instance_code VARCHAR(100),
  submitted_at TIMESTAMPTZ DEFAULT NOW(),
  approved_at TIMESTAMPTZ
);
```

## API 端点

### 提交审批
```
POST /api/internal/approval/submit
{ shop_id, operator_id, change_type, effective_from, reason }
→ 写入 shop_operator_changes (status=pending)
→ 调飞书 POST /open-apis/approval/v4/external_instances
→ 返回 { ok, instance_code }
```

### 飞书 webhook 回调
```
POST /api/feishu/approval-callback
← 飞书推送 event_callback (approval_instance 状态变更)
→ 验证签名
→ 根据 instance_code 找到 pending 记录
→ 若 APPROVED: 更新 shop_operators (is_primary + effective_from/to)
→ 若 REJECTED: changes.status = 'rejected'
→ 发飞书消息通知发起人
```

### 查询店铺负责人时间线
```
GET /api/internal/shop-operators/timeline?shop_id=39591
→ [{ operator_name, is_primary, effective_from, effective_to }]
```

### 查询变动历史
```
GET /api/internal/approval/changes?shop_id=39591
→ [{ change_type, operator_name, effective_from, status, reason }]
```
