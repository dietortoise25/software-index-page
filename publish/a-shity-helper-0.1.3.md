A Shity Helper v0.1.3

淘宝/天猫商品数据采集 Chrome 扩展

功能

- 单品采集 — 商品详情页一键提取标题、价格、SKU、主图、详情图等信息
- 批量采集 — 搜索/列表页批量提取商品，支持自动翻页
- 智能反风控 — 零注入架构，模拟人类浏览行为（随机滚动、延迟、悬停），降低触发验证码风险
- SKU 面板数据提取 — 支持解析淘宝 SKU 列表（规格、价格、库存）
- JSON 导出 — 采集结果导出为 schema.json 格式，兼容妙手/店八方等导入模板
- 多主题 — Ocean Breeze（默认）+ Midnight Bloom 暗色双主题
- 选项页 — 可自定义反风控参数（间隔时间、滚动行为等）

支持平台

淘宝（taobao.com）/ 天猫（tmall.com）
