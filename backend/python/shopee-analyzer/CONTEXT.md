# 选品比价 (Sourcing)

帮助运营从 Shopee 店铺导出的商品数据出发,在 1688 找到同款货源并获取其真实价格,为采购决策提供依据。

## Language

**以图搜货 (Image Search)**:
用 Shopee 商品主图在 1688 检索同款,返回候选商品列表。走 1688 游客态,无需登录。
_Avoid_: 搜图、图搜(口语可用,正式文档用"以图搜货")

**候选商品 (Candidate)**:
一次以图搜货针对单个 Shopee 商品返回的一个 1688 商品。
_Avoid_: Offer、货源(指代同一对象时统一用"候选商品")

**标价 (itemPrice)**:
候选商品在搜货结果里展示的"¥X 起"价格。是营销展示价,**不等于**任一具体规格的真实采购价。
_Avoid_: 1688 价、成本价(标价既不是成本也不是规格价)

**SKU 价格表 (SKU Price Table)**:
一个候选商品的全部规格(颜色/尺寸等)及各规格对应的真实价格、起订量等。是采购成本的唯一可信价格来源。
_Avoid_: SKU 价(单数易与某一行混淆;整张表用"SKU 价格表")

**SKU Provider**:
获取某候选商品 SKU 价格表的第三方数据源。是一个可插拔契约:输入候选商品 id,输出统一格式的 SKU 价格表。具体服务商(万邦 / JustOneAPI 等)是该契约的实现。
_Avoid_: 接口、爬虫(强调它是"可替换的数据源契约",而非某个具体接口)

**智能 SKU 匹配 (SKU Matching)**:
判断一个 Shopee 商品究竟对应候选商品 SKU 价格表中的哪些规格的能力。在缺少该能力时,直接取整表最低价计算成本会失真。属于后续推荐系统的职责,不在当前范围。

## Relationships

- 一个 **Shopee 商品** 经 **以图搜货** 得到多个 **候选商品**
- 一个 **候选商品** 拥有一张 **SKU 价格表**(经 **SKU Provider** 获取)
- **SKU 价格表** 含多个规格行;**标价** 是候选商品的展示价,与具体规格价相互独立
- **智能 SKU 匹配** 决定 **Shopee 商品** ↔ **SKU 价格表** 中规格行的对应关系(后续能力)

## Example dialogue

> **Dev:** "成本就用 SKU 价格表的最低价算,对吧?"
> **运营:** "不行。一个 1688 候选商品有十几个规格,我们 Shopee 上架的可能只对应其中两三个。直接取最低价会算错。得先有**智能 SKU 匹配**判断对应哪些规格,那是后面推荐系统的事。现在先把整张 **SKU 价格表** 抓全、展示出来就行。"

## Flagged ambiguities

- "1688 价格" 曾混指 **标价**(itemPrice,图搜展示价)和 **SKU 价格表** 里的规格价 — 已区分:成本只认 SKU 价格表,标价仅为搜货展示,不入成本计算。
